# 🌿 Nature’s Beauty — Embrace the Wild  
A Modern, Glassmorphic, Responsive Nature-Themed Website

Nature’s Beauty is a fully responsive, visually stunning, and modern landing-page style website built with  
**HTML5, CSS (Custom + Bootstrap 5), and Vanilla JavaScript**.  
It showcases beautiful photography, smooth animations, interactive UI components, and a clean aesthetic built for:

- Portfolio projects  
- Landing page demos  
- Photography showcase sites  
- Nature / travel / environment presentations  
- University or internship project submissions  

---

## ✨ Features

### 🎨 Modern UI/UX  
- Smooth glassmorphism cards  
- Gradient backgrounds  
- Animated hero banner with overlay  
- Soft hover animations  
- Clean, sharp typography (Poppins font)

### 📱 Fully Responsive Layout  
Optimized for all screen sizes:  
Mobile → Tablet → Desktop

### 🏞 Multiple Sections  
- **Hero Section** — Large banner with CTA and newsletter form  
- **About Section** — Information + beautiful side image  
- **Gallery Section** — Grid layout with hover zoom animations  
- **Contact Section** — Validated contact form  
- **Footer** — Social links + copyright

### 📬 Working UI Components (Demo)  
✔ Newsletter subscription popup  
✔ Contact form with validation  
✔ Animated scroll reveal  
✔ Theme toggle (Light/Dark inversion)  
✔ Responsive navigation menu  

### 🔍 Accessibility & UX  
- ARIA labels  
- Keyboard navigation support  
- Lazy-loading images  
- Clean semantic HTML
